# Teardown VR Mod — development

Проект доработки Teardown VR для полноценной игры в VR: стерео, две руки, инструменты, меню и интерфейс.

**Статус: аудит v0.22, исправление Lua-ошибки и собираемое нативное математическое ядро. Полная реализация ещё не готова.**

## Структура

- `mod/` — Lua-код и ресурсы v0.22; DisableMotionBlur теперь вызывается только при наличии API.
- `native/` — собственное ядро математики поз и асимметричных проекций; пока не подключено к игре.
- `vendor/v0.22/dxgi.dll` — оригинальный нативный модуль из MIT-пакета.
- `upstream/v0.22/` — исходная документация и установщики, сохранённые для справки. Не запускайте их из новой структуры проекта.
- `docs/BASELINE.md` — происхождение, ограничения и известные ошибки.
- `docs/ROADMAP.md` — порядок реализации и критерии проверки.
- `docs/TASKS.md` — задачи с приоритетами и статусами.
- `docs/ARCHITECTURE.md` — аудит протокола и координат v0.22.
- `docs/NATIVE_SOURCE_AUDIT.md` — проверенные публичные источники и решение по нативной реализации.
- `docs/BUILD.md` — зависимости, сборка и проверки без шлема.
- `docs/NEW_CHAT_PROMPT.md` — контекст и промпт для продолжения в новом чате.
- `scripts/Verify-Baseline.ps1` — проверка исходного импорта по SHA-256.
- `local/` — исключённые из Git локальные материалы для диагностики и сравнения.

## Начало работы

```powershell
powershell -NoProfile -File .\scripts\Build-Native.ps1
python -m pip install -r tests/requirements.txt
python -m unittest discover -s tests -v
```

Репозиторий сам ничего не устанавливает в игру. Рабочая установка и настройки ALVR при импорте не менялись.

Исходники оригинальной dxgi.dll не найдены в публичных ветках/релизах автора.
Собственное ядро собирается как tdvr_math.dll: это математика, пока без OpenXR,
DXGI-перехвата и игрового VR-рендера. Оно не заменяет vendor/v0.22/dxgi.dll.
Первоначальные SHA-256 сохранены; Verify-Baseline.ps1 теперь ожидаемо отмечает
изменённый mod/main.lua. Все остальные 12 файлов базы совпадают с манифестом.
